Ce face

Un server MCP care rulează local pe calculatorul tău și dă asistentului acces la trei surse publice și gratuite:

SursăCe conține
ANAF — registrul TVAdenumire, nr. reg. com., adresă, CAEN, plătitor TVA, TVA la încasare, split TVA, firme inactive, radiate, RO e-Factura
ANAF — bilanțurisituații financiare anuale: cifră de afaceri, profit/pierdere, active, datorii, număr de salariați
BNR — curs valutarcursul de referință de azi și din arhiva pe ani

Toate sunt endpoint-uri publice: nu ai nevoie de cont, de cheie de API sau de abonament la vreun agregator.

Tool-urile

anaf_firma

Un CUI: datele complete plus un verdict scurt — „OK" sau „ATENȚIE" dacă firma e inactivă, radiată sau neplătitoare de TVA.

anaf_firme

Până la 100 de CUI-uri într-un singur apel. Întoarce și listele separate de firme inactive, neplătitoare de TVA și negăsite — bun pentru curățat baza de clienți sau furnizori.

anaf_bilant

Situațiile financiare pe un an, cu indicatorii în lei și denumirea CAEN.

bnr_curs

Cursul zilei sau al unei date din trecut. Pentru weekend și sărbători întoarce ultima zi bancară.

bnr_conversie

Conversie între valute la cursul BNR dintr-o dată anume.

search_caen

Caută în nomenclatorul CAEN după cod (4754 sau prefixul 47) ori după cuvinte din denumire. Diacriticele nu contează.

search_company

Caută firma după denumire, nu după CUI — ANAF nu are așa ceva. Folosește lista Registrului Comerțului, indexată local. Cere o sincronizare unică.

Tutorial

1

Instalare

Ai nevoie doar de Python 3 — există deja pe macOS și Linux; pe Windows se ia de pe python.org.

git clone https://github.com/sergiudanstan/anaf-mcp.git
cd anaf-mcp
python3 anaf_mcp.py --firma 14399840

Dacă vezi un JSON cu "denumire": "DANTE INTERNATIONAL SA", serverul merge. Reține calea absolută — o folosești la pașii următori:

pwd    # ex: /Users/dan/anaf-mcp
       # → calea completă e /Users/dan/anaf-mcp/anaf_mcp.py
2

Claude Code

O singură comandă, din orice folder:

claude mcp add anaf -- python3 /CALEA/ABSOLUTA/CATRE/anaf-mcp/anaf_mcp.py

Adaugă -s user dacă vrei serverul disponibil în toate proiectele, nu doar în cel curent:

claude mcp add anaf -s user -- python3 /CALEA/ABSOLUTA/CATRE/anaf-mcp/anaf_mcp.py
claude mcp list          # anaf trebuie să apară cu ✓ connected

În sesiune, /mcp îți arată tool-urile încărcate. De acolo încolo ceri în limbaj natural:

verifică CUI 14399840 la ANAF
ia-mi bilanțul pe 2024 pentru 14399840 și spune-mi marja netă
am lista asta de CUI-uri din facturi — care sunt inactive sau neplătitoare de TVA?
cât era euro pe 30 iunie 2026?
convertește 12.500 EUR în RON la cursul din 15 martie 2026

Ștergi serverul cu claude mcp remove anaf.

3

Codex (OpenAI Codex CLI)

Editezi ~/.codex/config.toml și adaugi:

[mcp_servers.anaf]
command = "python3"
args = ["/CALEA/ABSOLUTA/CATRE/anaf-mcp/anaf_mcp.py"]

Pe versiunile recente de Codex CLI merge și direct din terminal:

codex mcp add anaf -- python3 /CALEA/ABSOLUTA/CATRE/anaf-mcp/anaf_mcp.py
codex mcp list

Repornești codex și ceri la fel, în limbaj natural.

Capcana uzuală: în Codex secțiunea se numește mcp_servers (cu underscore), iar în Claude mcpServers (camelCase). E cea mai frecventă greșeală de configurare.
4

Claude Desktop

Editezi ~/Library/Application Support/Claude/claude_desktop_config.json pe macOS, sau %APPDATA%\Claude\claude_desktop_config.json pe Windows:

{
  "mcpServers": {
    "anaf": {
      "command": "python3",
      "args": ["/CALEA/ABSOLUTA/CATRE/anaf-mcp/anaf_mcp.py"]
    }
  }
}

Repornești complet aplicația (Quit, nu doar închis fereastra). Tool-urile apar la iconița MCP din bara de input.

5

Căutarea după denumire (sincronizare unică)

search_company are nevoie de lista firmelor de la Registrul Comerțului. Se descarcă o singură dată:

python3 anaf_mcp.py --sync-onrc

Trage od_firme.csv de pe data.gov.ro (~650 MB) și construiește un index SQLite local în ~/.cache/anaf-mcp/. Durează câteva minute, o singură dată — ONRC republică fișierul lunar. Fără el, restul tool-urilor merg normal; doar search_company spune că indexul lipsește.

Fluxul firesc: cauți după nume → iei CUI-ul → îl dai la anaf_firma pentru datele fiscale la zi.

6

Verificare din terminal, fără client

Fiecare tool are un echivalent CLI — util ca să vezi dacă problema e la server sau la client:

python3 anaf_mcp.py --firma RO14399840
python3 anaf_mcp.py --bilant 14399840 2024
python3 anaf_mcp.py --curs 2026-06-30
python3 anaf_mcp.py --caen instalatii electrice
python3 anaf_mcp.py --cauta dante international
python3 anaf_mcp.py --test

Cache și limite

Cache pe disc în ~/.cache/anaf-mcp/ (sau ANAF_MCP_CACHE_DIR), cu prospețime diferită per tip de date: 6 ore datele de firmă, 30 de zile bilanțurile, 30 de minute cursul zilei, 90 de zile arhiva anilor încheiați.

Limitele ANAF sunt respectate de server: maximum 100 de CUI-uri per apel și un apel pe secundă — cererile se serializează și așteaptă singure.

Ce nu acoperă

Contracte și achiziții publice (SEAP/SICAP). API-ul public de la e-licitatie.ro răspunde, dar filtrele după firmă, dată sau cod CPV sunt ignorate de server — întoarce mereu aceeași felie fixă de 2000 de înregistrări. Fără contractul corect de filtrare, orice tool peste el ar da rezultate greșite, așa că nu există aici.

Clasamente „top firme pe județ/CAEN/an". Cer baza de bilanțuri a tuturor firmelor, ingerată într-un backend — nu se pot face dintr-un fișier local.

Asociați, administratori, istoric mențiuni. ONRC le dă doar prin RECOM, contra cost. Lista reprezentanților legali există totuși ca fișier deschis pe data.gov.ro, dacă vrei să o indexezi la fel ca lista firmelor.
